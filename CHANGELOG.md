# Changelog

Both apps show the entries added since the version they ran before ("What's new" after an update, the
whole list in the settings). Newest first. Every version has a German and an English list with the same
points. A version heading is any unique text (the date; a second release on the same day gets a suffix,
e.g. `2026-11-02 b`) - only the order in this file matters. Rules: keep the format, every user-facing
change gets a line, no empty versions.

## 2026-11-02

### DE
- Nach einem Update zeigt die App, was neu ist – die ganze Liste steht in den Einstellungen unter „Was ist neu“.
- Momentum ist jetzt Open Source: Bug-Reports und Feature-Wünsche aus der App landen als Issues im öffentlichen GitHub-Repo.

### EN
- After an update the app shows what's new – the whole list lives in the settings under "What's new".
- Momentum is open source now: bug reports and feature requests from the app become issues in the public GitHub repo.
